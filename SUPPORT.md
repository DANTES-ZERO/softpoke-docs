# Support

For problems with SoftPoke, open an issue in this repository (Issues tab, "Bug report").

Please include:

* the SoftPoke and Unreal Engine versions,
* your GPU and driver,
* the headset, if the problem is about VR,
* an excerpt of `Saved/Logs/<Project>.log` (the `LogSoftPoke` lines),
* for bake problems, the files `manifest.json` and `quality_report.json` from the bake work folder.

Do not attach models you have no right to share.

Support covers the unmodified plugin and the supported matrix (Windows 64, UE 5.8, D3D12 SM6, NVIDIA RTX validated, adult humanoid characters). It does not include custom bakes.

Before reporting, see [Changelog, known issues, FAQ](docs/ChangelogFaq.md).
